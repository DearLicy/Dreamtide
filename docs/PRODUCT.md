# Dreamtide V2 产品规格

## 定位

**触梦 Dreamtide** 是本地优先、BYOK、纯本地 AI 社交的梦境恋爱 IM。用户通过梦设、AI 角色、关系状态、长期记忆、导演模式和梦境空间，经营可持续发展的虚构恋爱关系。

产品不是通用 AI 助手，也不是带角色卡的聊天客户端。

## 核心结构

### 三个根页面

1. **消息**：最近会话、置顶、未读、免打扰、搜索和关系阶段。
2. **联系人**：角色、分组、关系和群聊入口。
3. **动态**：梦境空间，用户与 AI 角色发布文字动态、点赞和评论。

只有三个根页面显示底部导航。聊天与所有管理页面使用全屏二级路由。

### 侧滑资料

根页面头像打开侧滑抽屉：

- 本地用户资料；
- 切换梦设；
- 收藏与记忆；
- 隐私与安全；
- 数据与备份；
- 设置；
- 夜间模式；
- 关于。

## 关系模型

一条关系由以下内容唯一确定：

- 一个本机用户；
- 一套梦设 `UserPersona`；
- 一位 AI 角色 `Character`；
- 一段 `Relationship`；
- 一个参与者感知的 `ChatThread`；
- 一组关系级边界与内容上限。

同一角色可以拥有多条平行关系，但梦设、记忆、称呼、场景和边界彼此独立。

## 长期记忆

记忆类别：

- 用户信息；
- 关系信息；
- 共同经历；
- 重要承诺；
- 情绪记忆；
- 剧情状态；
- 用户边界。

记忆必须可查看来源、编辑、固定和删除。固定项、边界项和当前输入相关的记忆优先进入提示词。

长对话会在正常回复完成后由同一 BYOK 供应商单独、静默地归纳旧对话，结果保存在本地会话备忘，并随之后的主对话提交。整理失败不影响聊天，也不覆盖上一版备忘；原始消息仍保留。整理涉及的历史片段会额外发送给当前模型供应商。该请求只在应用运行且用户仍使用聊天时触发，不在应用关闭后静默调用；每次最多整理 16 条旧消息、保留最近 8 条原文。自动事实保留消息来源，不会自动新增或覆盖用户边界。

## 导演与场景

导演模式只调整当前剧情，不修改角色卡：

- 节奏：慢热 / 自然 / 强推进；
- 旁白比例；
- 角色主动性；
- 场景亲密程度；
- 本轮自然语言指令；
- 重置场景但保留长期关系记忆。

## 内容级别

| 级别 | 体验 |
| --- | --- |
| SFW | 日常、恋爱、友情、剧情 |
| Mature | 成熟恋爱、暧昧、性感表达 |
| NSFW | 明确成年、自愿的虚构角色之间的成人文字 RP |

全局上限限制所有关系；每段关系可以更低，但永远不能更高。

## 梦境空间

V2.0 只支持文字动态：

- 用户发布文字；
- AI 角色发帖；
- 点赞；
- 评论与 AI 回复。

图片、视频、AI 图像与剧情相册安排在 V2.3。

## 纯本地边界

- 没有真实用户好友；
- 没有关注、私信、举报、云端社区；
- 没有 Dreamtide 账号；
- 没有云同步；
- 模型请求直接从本机发往用户配置的供应商；
- 所有角色、动态、关系和记忆均为本地数据。

## 路线图

| 版本 | 能力 |
| --- | --- |
| V2.0 | 三栏 IM、单聊、梦设、关系、记忆、导演、边界、文字动态 |
| V2.1 | 生活状态、关系日历、主动消息、本地通知、语音消息 |
| V2.2 | 多角色群聊、独立与共享记忆、发言调度 |
| V2.3 | 动态媒体、AI 图像、剧情相册、消息分支 |
| V2.4 | 实时语音、视频剧情、触觉场景编排 |

## 当前交互修订（2026-11-19）

- 首次启动为空白产品；不预置梦设、角色、消息、记忆或动态。
- 默认连接 DeepSeek 官方，模型从认证接口拉取并选择，禁止用模拟目录掩盖失败。
- 未配置供应商时不回复模拟内容，保留输入草稿。
- AI 的中英文括号动作拆为气泡外旁白，兼容 V1 的单星号与引用旁白。
- 使用 Forui 表单、按钮与弹层；取消列表与切栏位移动画，缩小圆角并移除重阴影。
- 文字动态只保存真实输入，不自动插入模拟角色评论或点赞。角色模型驱动的动态互动仍待开发。
